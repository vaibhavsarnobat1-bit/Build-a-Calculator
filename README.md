A feature-packed, next-generation web calculator designed with modern aesthetics, glassmorphism styling, interactive WebGL2 water-ripple background physics, and rich functionality.

---

## ✨ Features

- **Dual Modes (Standard & Scientific)**:
  - Basic arithmetic: addition, subtraction, multiplication, division, percentage, sign toggles.
  - Advanced scientific: trigonometric functions (`sin`, `cos`, `tan`), logarithmic (`log`, `ln`), exponential (`e^x`, `x^y`, `x²`), square root (`√`), factorial (`n!`), and constants (`π`, `e`).
- **Interactive WebGL2 Water Ripple Background**:
  - Fluid physics canvas that dynamically responds to mouse movement and clicks.
- **Dynamic Calculation History**:
  - Live history tape tracking calculations with one-click recall and clear options.
- **Audio Feedback**:
  - Interactive sound feedback toggle for button clicks.
- **Integrated Unit & Utility Converters**:
  - Quick sidebar converters for Length, Mass, Temperature, and GST/Tax calculation.
- **Keyboard Navigation Support**:
  - Full keyboard bindings for fast number entry and shortcuts (`Enter` for calculate, `Escape` for clear, `Backspace` for delete).
- **Responsive & Cyber Neon Aesthetic**:
  - Ultra-clean dark theme with ambient glowing gradients and smooth micro-animations.

## 💻 How to Run Locally

### Option 1: Direct in Browser
Simply double-click `index.html` in your file explorer to open it directly in any modern web browser.

### Option 2: Live Server with Public Tunnel
1. Ensure [Node.js](https://nodejs.org/) is installed.
2. Double-click `start-live.bat` (or run `node live.js` in terminal).
3. The server will start on `http://localhost:8081` and generate a public live link for mobile and remote testing.
